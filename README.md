# Karishma K. — AI & Software Portfolio

A responsive portfolio website created from the resume provided.

## Files
- `index.html` — page structure and portfolio content
- `style.css` — dark UI, responsive layouts, animations, and visual styling
- `script.js` — mobile navigation and dynamic footer year

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in a browser.
3. For editing, open the folder in VS Code.

No build tools or installation are required. Google Fonts are loaded from the internet; the site still works if they are unavailable.

## Personalise before publishing
- Verify the phone number and email address you want to display.
- Update the LinkedIn URL if needed.
- Replace the illustrative skill bars with your actual skill levels.
- Add GitHub/project links and real project screenshots when available.
- Confirm your CGPA and academic details are current.
- The profile illustration is a stylised initial, not a photograph.
